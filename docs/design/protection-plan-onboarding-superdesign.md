Simulator baseline: the current app was built and run on the pinned iPhone 17 Pro simulator. The live SwiftUI paywall confirmed the production viewport rhythm: 402x874 points, soft cream/coral background, top segmented progress, large rounded white cards, fixed bottom CTA stack, and compact legal/footer area. The new Superdesign interaction and element boards below use that live baseline while replacing old shake/paywall copy with the protection-plan direction.

## Notes For PRD / Issues

- Use `docs/adr/0003-protection-plan-onboarding.md` as the source of truth for flow order, activation semantics, and permission/paywall branching.
- Treat the Superdesign drafts as static composition references. Use the SwiftUI interaction blueprint for motion, haptics, proof-scene choreography, and implementation-native polish.
- Use the SwiftUI element visual kit when slicing component/system issues, and use the interaction storyboards when slicing proof-scene, transition, and motion issues.
- Use `CONTEXT.md` glossary terms exactly: Draft Pill Protection Plan, Distraction Choice, Draft Blocked App Choice, Delay Consequence, Risk Window, Reminder-Only Onboarding Completion, and Protection Plan Activation.
- Link issue slices to individual screen drafts above rather than the whole project when the issue scope is screen-specific.
