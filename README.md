# Pillie

This is the Pillie iOS app repository — a medication reminder app built with Swift and SwiftUI.

## Development

### Repository structure

- **`Pillie/`** — Main Xcode project containing the iOS app source, extensions, tests, build scripts, and tools
- **`docs/`** — Project documentation including ADRs, design notes, release guides, and legal pages
- **`scripts/`** — Repo-level utility scripts (e.g. privacy disclosure validation)
- **`.agents/`** — Agent skills and configuration used by Codex AI agents
- **`.claude/`** — Claude Code skills and configuration
- **`.codex/`** — Codex environment configuration for local iOS development
- **`.github/`** — GitHub Actions workflows for CI/CD and automated tasks
